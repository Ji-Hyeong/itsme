# 첫 프로토타입 인수 기준

## 검증할 핵심 루프

`시작 → 질문 3개 → 현재의 나 → 기록 갱신 → 변화 → 공개 선택 → 실제 모습 미리보기`

첫 프로토타입은 가입, 친구, 피드와 Backend 연동보다 이 루프가 평가나 비교 없이 자연스럽게
이어지는지를 먼저 검증한다.

## P0 인수 기준

1. 사용자는 질문에 답하거나 건너뛸 수 있으며 건너뛰어도 진행이 막히지 않는다.
2. 취향, 성격과 배우는 중인 것의 대표 질문에 답하면 `현재의 나`에 즉시 반영된다.
3. 새 기록은 별도 공개 행동 전까지 항상 `나만 보기`다.
4. MBTI는 진단이 아닌 선택적 자기표현 정보라고 안내한다.
5. 기록을 갱신하면 이전 답, 당시 맥락과 기록 시점이 보존된다.
6. 변화 화면은 차이를 보여주되 성장, 퇴보 또는 우열을 판정하지 않는다.
7. 공개 전환은 항목별 명시적 행동이고 공개할 결과를 미리 확인할 수 있다.
8. 공개 미리보기와 방문자 화면은 같은 공개 응답을 사용하며 비공개 필드는 응답에 없다.
9. 공개 항목이 없어도 오류나 미완성으로 표현하지 않는다.
10. 키보드와 스크린리더로 핵심 루프를 수행할 수 있고 축소 모션 설정을 존중한다.
11. 저장 중 중복 제출을 막고 실패 시 입력을 유지한 채 재시도할 수 있다.
12. 핵심 화면에는 좋아요, 팔로워, 조회수, 순위, 완성도와 경쟁형 연속 기록이 없다.

## 프로토타입 제외 범위

- 실제 로그인, Backend와 영구 저장
- 친구, 댓글, 메시지와 공통 관심사
- AI 진단, 추천과 자동 추론
- 외부 음악, 영화와 책 서비스 연동
