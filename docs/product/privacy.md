# 프라이버시 원칙

## 공개 범위

MVP는 `private`와 `public` 두 범위로 시작하되, 데이터와 API에서는 향후 제한 공개
범위를 추가할 수 있는 명시적 enum으로 표현한다. 새 항목의 기본값은 항상 `private`다.

## 안전한 공개

- 저장과 공개를 하나의 행동으로 합치지 않는다.
- 공개 범위를 바꾸기 전에 변경되는 항목과 대상을 명확히 보여준다.
- 공개 프로필 미리보기는 실제 공개 응답을 사용해 결과 불일치를 방지한다.
- 공개 프로필 API는 소유자 API와 별도 응답 모델을 사용한다.
- 공개 해제와 삭제가 캐시 및 공유 화면에 반영되는 정책을 계약에 명시한다.

## 민감 정보

- 성별, 성격, 관계, 감정, 약점과 자유 서술은 선택 입력이다.
- 사용자가 입력하지 않은 민감 정보를 AI나 행동 데이터로 추론해 프로필에 추가하지 않는다.
- 민감한 원문을 URL, 로그, 오류 응답과 분석 이벤트에 포함하지 않는다.
- 데이터 수집 목적, 보존 기간, 내보내기와 삭제 결과를 사용자가 이해할 수 있게 설명한다.

## 삭제

숨김, 공개 해제, 개별 기록 삭제와 계정 삭제를 서로 다른 행동으로 정의한다. 구현 전
원본 데이터, 버전 이력, 파생 데이터, 검색 인덱스와 캐시에 대한 삭제 정책을 확정한다.
