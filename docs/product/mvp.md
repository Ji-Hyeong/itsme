# MVP 범위

## Must

- 선택형과 짧은 서술형 질문을 섞은 점진적 온보딩
- 성격, 가치관, 취향, 강점, 배우는 중과 도움 필요한 것 기록
- 카테고리별로 현재 기록을 보여주는 `현재의 나`
- 기록의 근거, 변화 이유와 다음 시도 추가
- 같은 항목을 갱신할 때 과거 버전과 시점을 보존하는 타임라인
- 항목별 `나만 보기`와 `공개` 범위 설정
- 다른 사람이 보는 결과와 동일한 공개 프로필 미리보기
- 자기 기록 수정과 삭제
- 정상, 빈 상태, 로딩, 오류, 권한 없음과 공개 항목 없음 처리

## Later

- 매주 하나씩 제공하는 자기 탐색 질문
- 친구와 공통 관심사를 점수 없이 발견하는 교집합
- 음악, 영화와 책 서비스에서 사용자가 선택한 항목 가져오기
- 기록 내보내기와 개인 회고 리포트
- 친구에게 답변을 요청하거나 대화 소재를 제안하는 기능

## Won't for MVP

- 무한 소셜 피드, 좋아요, 팔로워 수, 조회수와 인기 랭킹
- 사용자 간 궁합 점수와 강점 순위
- AI 기반 성격, 정신건강 또는 능력 진단
- 공개 댓글과 다이렉트 메시지
- 범용 습관, 건강과 위치 자동 추적

## 핵심 인수 기준

1. 사용자는 일부 질문을 건너뛰면서 최소 세 가지 카테고리의 기록을 만들 수 있다.
2. 작성 결과가 `현재의 나`에 카테고리별로 반영된다.
3. 새 항목은 나만 보기로 저장되고 사용자가 항목별로 공개를 선택할 수 있다.
4. 공개 전 미리보기와 실제 공개 프로필의 내용이 일치한다.
5. 다른 사용자는 공개가 허용된 데이터만 받을 수 있으며 비공개 필드는 응답에도 포함되지 않는다.
6. 기록을 갱신하면 이전 값과 당시 맥락이 보존된다.
7. 수정과 삭제 결과가 개인 화면, 공개 프로필과 캐시에 일관되게 반영된다.
8. 핵심 화면에 좋아요, 팔로워, 조회수, 순위 또는 우열 점수가 존재하지 않는다.
9. 키보드와 스크린리더로 핵심 여정을 완료할 수 있고 축소 모션 설정을 존중한다.
10. PO, Designer, Frontend와 Backend가 동일한 인수 기준과 권한 행렬로 검증한다.
