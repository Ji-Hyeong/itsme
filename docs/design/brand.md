# it’sME 브랜드 로고 시스템

## 브랜드 표기

기본 워드마크는 `it’sME`다. `it’s`는 Regular, `ME`는 SemiBold로 표현하고 띄어쓰지 않는다.
표시용 워드마크에는 곡선형 apostrophe `’`를 사용한다. 접근성 이름, 검색어, URL, 파일명과
시스템 대체 텍스트에는 ASCII 표기 `it'sME`를 사용한다.

현대적인 산세리프의 단정한 골격을 유지하며 `ME`의 굵기 차이만으로 시선을 모은다. 넓은
자간, 전부 대문자인 `ITS ME`, 줄바꿈 워드마크와 별도 슬로건 결합은 사용하지 않는다.

## 고유 심볼: Scene M

`Scene M`은 높이가 다른 세 개의 둥근 세로 장면이 겹쳐 추상적인 소문자 `m`을 이루는
심볼이다. 여러 시기의 기록과 장면이 겹쳐 지금의 내가 된다는 제품 철학을 나타낸다. 세
장면은 우열이나 시간의 상승·하락을 뜻하지 않는다.

- 왼쪽 장면: Sage `#718477`
- 중앙 장면: Indigo `#4457A6`
- 오른쪽 장면: Apricot `#C87D5B`
- 세 장면은 불투명한 단색 면으로 겹치며 투명도, 혼합 모드와 그라데이션을 사용하지 않는다.
- 중앙 장면을 시각적 축으로 두되 세 장면의 폭과 모서리 반경은 동일하게 유지한다.
- 상단과 하단 높이 차이로 `m`의 리듬을 만들고 문자 획이나 얼굴 형태를 추가하지 않는다.

### 구성 기준

40×40 단위 그리드를 기준으로 바깥 장면은 폭 11·높이 30·반경 5.5, 중앙 장면은
폭 12·높이 23·반경 5.5로 한다. 각 장면은 1단위씩 맞물린다. 광학 보정은 허용하되
가운데가 낮아 소문자 `m`으로 읽히는 외곽 실루엣을 유지한다.

컬러형은 왼쪽, 오른쪽, 중앙 순으로 쌓아 중앙 인디고 장면이 겹침의 중심이 되게 한다.
단색형은 동일한 외곽 실루엣과 높이 차이를 하나의 색으로 표현한다.

## 로고 조합

- 기본 가로형: `Scene M` 왼쪽, `it’sME` 오른쪽
- 심볼과 워드마크 사이 간격: 중앙 장면 폭의 0.75배
- 보조 세로형: `Scene M` 위, `it’sME` 아래. 정사각형 공간에서만 사용한다.
- 심볼 단독형: 앱 아이콘, 파비콘, 알림 아이콘과 32px 이하의 좁은 공간에 사용한다.
- 워드마크 단독형: 문서 제목, 법적 표기와 심볼이 이미 가까이 노출된 화면에 사용한다.

## 최소 크기와 보호 여백

- 기본 가로형 최소 높이: 디지털 20px, 인쇄 7mm
- 워드마크 단독 최소 높이: 디지털 16px, 인쇄 6mm
- Scene M 단독 최소 크기: 디지털 16×16px, 인쇄 5×5mm
- 16–23px Scene M은 단색형만 사용한다.
- 24px 이상에서 컬러형을 사용할 수 있으며 세 색의 구분이 흐려지면 단색형으로 전환한다.

보호 여백 `x`는 Scene M 중앙 장면 폭과 같다. 모든 로고 조합의 상하좌우에 최소 `1x`를
확보한다. 앱 아이콘에서는 심볼 전체를 Android adaptive icon 중앙 안전 영역 66% 안에 둔다.
다른 문구, 아이콘, 화면 가장자리와 보호 여백을 공유하지 않는다.

## 컬러와 단색 사용

- 컬러형은 White `#FFFFFF` 또는 Cloud `#F4F5F7` 단색 배경에서만 사용한다.
- Indigo 배경에서는 White `#FFFFFF` 단색형을 사용한다.
- 흰 배경의 단색형은 Indigo `#4457A6`, 흑백 인쇄는 100% Black 또는 White를 사용한다.
- 사진이나 패턴 위에 직접 놓지 않는다. 불가피하면 충분한 대비의 단색 면을 먼저 확보한다.
- 고대비 모드와 Android 테마 아이콘은 색상 구분에 의존하지 않는 단색 Scene M을 사용한다.
- 로고 색은 UI 상태색으로 의미를 확장하지 않는다. Sage·Indigo·Apricot의 순서와 값을 임의로
  교환하지 않는다.

## 앱 아이콘

대표 앱 아이콘은 Indigo `#4457A6` 단색 바탕 중앙에 White 단색 `Scene M`을 배치한다.
작은 홈 화면과 검색 결과에서 식별성을 유지하기 위해 컬러 세 장면, 워드마크, 테두리와
그림자를 함께 넣지 않는다.

- iOS 아이콘: 모서리가 없는 1024×1024 불투명 원본. OS가 모서리를 적용한다.
- Android foreground: 투명 배경의 White Scene M. 중앙 66% 안전 영역 안에 배치한다.
- Android background: Indigo `#4457A6` 단색
- Android monochrome: 색과 투명도 효과가 없는 단일 Scene M 마스크
- Web favicon: 16px에서는 단색 실루엣, 32px 이상에서는 Indigo 바탕과 White 심볼 사용
- Splash: Cloud 배경 중앙의 Indigo 단색 Scene M을 사용하며 워드마크와 문구를 추가하지 않는다.

## 앱 자산 경로

아래는 Expo 설정이 소비하는 최종 출력 경로다. 로고 원본은 벡터로 관리하고 각 PNG를 해당
크기와 색상 규칙에 맞춰 내보낸다.

- iOS 및 공통 앱 아이콘: `apps/client/assets/images/icon.png`
- Android 전경: `apps/client/assets/images/android-icon-foreground.png`
- Android 단색 테마 아이콘: `apps/client/assets/images/android-icon-monochrome.png`
- Web favicon: `apps/client/assets/images/favicon.png`
- Splash 심볼: `apps/client/assets/images/splash-icon.png`
- Scene M 벡터 원본: `apps/client/assets/brand/`

Android adaptive icon의 설정 색상도 Indigo `#4457A6`과 일치해야 한다.

## 모바일 화면 사용

- 360px, 390px와 430px 네이티브 화면을 기준으로 하며 Web은 최대 480px 중앙 preview로만 사용한다.
- 화면 배경은 Cloud 또는 White 단색을 사용하고 로고 뒤에 파스텔 glow나 그라데이션을 넣지 않는다.
- 모바일 header에서 기본 가로형을 사용할 때 보호 여백을 포함해 콘텐츠 폭을 넘지 않게 한다.
- 32px 이하의 내비게이션, 로딩과 작은 상태 영역에서는 Scene M 단독형을 사용한다.

## 금지 사항

- 사람 얼굴, 상반신, 프로필 원형 실루엣이나 카메라 프레임으로 변경하지 않는다.
- 체크, 별, 왕관, 그래프, 퍼센트와 상승 화살표를 결합하지 않는다.
- 세 장면의 높이 차이를 진행 단계, 순위나 성장 그래프로 설명하지 않는다.
- 장면의 순서, 색, 비율, 겹침 방향을 바꾸거나 장면 하나만 임의로 회전하지 않는다.
- 형광색, 무지개·메시 그라데이션, 투명 겹침과 입체 그림자를 적용하지 않는다.
- 로고를 늘이거나 기울이고 외곽선, 광택, 질감과 애니메이션을 추가하지 않는다.
- 앱 아이콘 안에 `it’sME` 전체 워드마크나 부가 문구를 넣지 않는다.
- Indigo 바탕에 컬러형을 사용하거나 대비가 불충분한 사진 위에 직접 배치하지 않는다.
