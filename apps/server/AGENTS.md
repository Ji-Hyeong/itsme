# 잇츠미 Backend 지침

루트 `AGENTS.md`의 제품 원칙과 엔지니어링 규칙을 우선 적용한다.

## 보안과 데이터 경계

- 인증된 사용자 ID는 bearer 세션에서만 얻고 요청 본문의 사용자 ID를 신뢰하지 않는다.
- 세션 원문, 비밀번호와 사용자의 자유 서술을 로그·URL·분석 이벤트에 남기지 않는다.
- 신규 기록은 항상 `private`으로 생성하고 공개 판정은 SQL projection과 별도 DTO에서 강제한다.
- 기록 수정은 과거 버전을 보존하고 기존 공개 동의를 자동으로 철회한다.
- 삭제는 현재 기록, 모든 버전과 맥락을 같은 트랜잭션에서 제거한다.

## 계약과 검증

- `../../contracts/openapi/itsme.yaml`을 공개 API 계약의 단일 진실 공급원으로 사용한다.
- Flyway 마이그레이션은 이미 배포된 파일을 수정하지 않고 새 버전으로 추가한다.
- 인증, 소유권, 공개 projection과 삭제 경계 변경에는 통합 테스트를 추가한다.

## 프로젝트 변경 이력

- 2026-07-22: Spring Boot 4.1, Kotlin 2.2, Java 17, PostgreSQL 17 기반 내부 알파 서버를
  구성하고 초대 계정 인증, 기록 버전, 공개 범위와 영구 삭제 API를 추가했다.
- 2026-07-22: 로컬 모바일 Web 미리보기용 제한적 CORS와 PostgreSQL CI 검증을 추가했다.
- 2026-07-22: 버전 조건부 수정, 10분·1회용 공개 미리보기 승인, 계정 회수, 로그인 제한과
  검색 색인 차단을 추가하고 내부 record ID를 공개 DTO에서 제거했다.
- 2026-07-29: PostgreSQL JDBC가 `Instant` 파라미터 타입을 추론하지 못하는 문제를 해결하기
  위해 모든 SQL 시간 입력을 명시적인 `Timestamp` 경계로 통일했다.
